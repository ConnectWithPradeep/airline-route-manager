# Airline Route Manager — College Showcase Website

A browser-based demonstration of an Airline Route Manager using JavaScript implementations of common tree and graph data structures and algorithms.

## Run the website

1. Extract `airline_route_manager_showcase_fixed.zip` to a folder.
2. Open the extracted folder.
3. Double-click `index.html` to open it in Chrome or Edge.
4. Use the left navigation menu to explore the modules.

No installation, server, database, login, or API key is required. Airport, flight, and graph data are saved in the browser's local storage. Use **Reset Demo** to restore the sample data.

## Main modules

- Dashboard and activity log
- Airport and flight management
- General Tree, BST, and AVL demonstrations
- Graph representation and visualization
- BFS / DFS, SCC, topological ordering, and Dijkstra route demonstrations
- Prim and Kruskal minimum spanning tree demonstrations
- Fare expression tree calculator
- Benchmark and automated-test demonstration panels

## Important notes for the showcase

- This is a local browser demonstration, not a production airline booking or ticketing system.
- The website is an additional visual showcase. It does not replace the original DSA console application or its report if those are required for submission.
- Algorithm results depend on the graph and data currently entered. Use small sample graphs during a live demonstration and explain the algorithm steps.
- Browser timing measurements vary by computer and browser. Treat them as illustrative empirical measurements, not universal performance claims.
