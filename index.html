    Core Theoretical Complexity & Design Principles
    
                                
    === AIRLINE ROUTE MANAGER: DSA THEORETICAL ANALYSIS ===

1. Design Technique and Problem Type:
- Greedy Algorithms: Used in Dijkstra's shortest path and Prim's/Kruskal's MST, making locally optimal choices at each step to find global optimization.
- Divide and Conquer / Tree Balancing: Used in AVL rotations and merge sort for Kruskal's edge sorting.
- Dynamic Programming / Graph Traversals: BFS/DFS and Kosaraju's SCC.

2. Correctness Explanations:
- Dijkstra: Correct for non-negative edge weights because once a vertex is finalized with minimum distance, no subsequent path can offer a shorter distance.
- Prim & Kruskal: Matroid theory guarantees that greedily selecting minimum weight edges without forming cycles yields a valid Minimum Spanning Tree/Forest.

3. Operation-Count Analysis:
- BFS: O(V + E) since each vertex and edge is visited a constant number of times.
- Array-based Dijkstra: O(V^2 + E). Finding the minimum unvisited vertex takes O(V) across V iterations, plus edge relaxation.
- Array-based Prim: O(V^2 + E).
- Kruskal: O(E log E) dominated by edge sorting.

4. BST Insertion Analysis:
- Best Case: O(log N) for balanced trees.
- Worst Case: O(N) when inserting sorted keys into an unbalanced BST.
- Average Case: O(log N) for random inputs.

5. AVL Height Proof via N(h) = N(h-1) + N(h-2) + 1:
- Minimum nodes N(h) required for height h is sum of minimum nodes of subtrees of height h-1 and h-2 plus root, proving height is strictly bounded by 1.44 log2 N.

6. Amortized Analysis of Union-Find:
- Path compression and union by rank yields an almost constant time complexity of O(alpha(N)) per operation, where alpha is the inverse Ackermann function.

7. Comparison-Sorting Lower Bound for Kruskal:
- Comparison-based sorting of E edges requires Omega(E log E) time in the worst case.

     About Airline Route Manager - DSA Project
    
                        
    
                        
    
                            
    A complete, production-grade Data Structures and Algorithms console and browser-based application built for college engineering evaluation.
    
                            
    
                            
    Modules Implemented:
    
                            
      
                                
    • Module A (Trees): General Tree (Country-Airport hierarchy), Flight BST, Self-Balancing AVL Tree with rotations and 10,000 random operations verification, Postfix Expression Tree for fare calculation.
      • 
                                
    • Module B (Graphs): Graph ADT (Adjacency Matrix & List with representation switching and memory comparison), BFS & DFS with edge classification, Kosaraju's SCC, Kahn's & DFS Topological Sorting with cycle detection, Array-based Dijkstra, and Prim's & Kruskal's MST (Minimum Spanning Forest for disconnected graphs).
      • 
                                
    • Module C (Algorithm Analysis): Rigorous empirical benchmarking and theoretical complexity proofs.
      • 
                            
    
                            
    Developed with pure vanilla JavaScript algorithms mirroring the Python DSA architecture. All data persists securely in browser localStorage.
